# 🍕 Web Pizza Project

โปรเจคเว็บไซต์ร้านพิซซ่า พัฒนาด้วย PHP และ MySQL  
เป็นงานที่ทำตอนเรียนปี 2 เพื่อฝึกสร้าง Web Application เบื้องต้น

---

## 📌 รายละเอียดโปรเจค

เว็บไซต์นี้สามารถ:

- เข้าสู่ระบบ
- แสดงเมนูพิซซ่าทั้งหมด
- ดูรายละเอียดพิซซ่าแต่ละรายการ
- เลือกขนาดพิซซ่า (มีการคำนวณราคาเพิ่มตามขนาด)
- เพิ่มสินค้าไปยังตะกร้า
- ร้านค้าสามารถเพิ่ม / แก้ไข / ลบ เมนูได้

---

## 👤 ระบบผู้ใช้

มีผู้ใช้งาน 2 ประเภท

### 🧑 Customer
- ดูเมนูพิซซ่า
- ดูรายละเอียดสินค้า
- เลือกขนาด
- เพิ่มลงตะกร้า

### 🧑‍🍳 ShopOwner
- จัดการการจัดส่งเมนูพิซซ่า
- เพิ่ม / แก้ไข / ลบ ข้อมูลสินค้า

---

## 🛠 เทคโนโลยีที่ใช้

- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript

---

## 🧠 สิ่งที่ได้เรียนรู้

- การเชื่อมต่อฐานข้อมูลด้วย PHP
- การใช้ Session ในระบบ Login
- การเขียน SQL Query
- การทำ CRUD (Create, Read, Update, Delete)
- การทำหน้าเว็บหลายหน้าเชื่อมต่อกัน
